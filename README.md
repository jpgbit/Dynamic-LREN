# Dynamic-LREN
# AI韩系清冷科技肖像生成交互展示页
## 项目简介
本项目是一套基于前端实现的AI人像生成效果展示单页网站，核心包含两大核心能力：
1. 完整AI人像生成提示词体系：支持证件照一键转化两种风格肖像——韩系高级影视人像、韩系极简未来轻机械人机融合肖像；严格保留原图人物五官、脸型、辨识度，不丢失原生人物特征；
2. Hero区域交互式图片Reveal光罩遮罩特效：基于Canvas径向渐变遮罩实现鼠标跟随圆形柔光探照效果，鼠标滑动区域展示风格化生成图，其余区域展示原始证件照，搭配动态数据流数字文字动画，适配桌面端+移动端。

项目整体UI极简高级，适配商业人像展示、AI绘画作品预览、人像生成工具产品官网场景。

## 核心AI生成提示词（项目内置）
### 风格1：韩系高级影视清冷肖像（基础人像）
基于上传证件照原图生成，强制保留人物全部原生特征：脸型、五官比例、眼神气质、发型走向、肤色、面部辨识度，保证一眼可识别为同一人。
- 构图：胸部以上半身肖像，人物微侧三分之四侧面，姿态自然沉稳自信
- 服装：哑光深色简约韩系修身正装，炭黑/深灰休闲西装、垂感衬衫，无花哨装饰
- 气质：清冷禁欲、内敛成熟韩剧男主氛围感
- 光影：韩式棚拍柔和侧柔光，保留真实皮肤细节，立体细腻电影级光影
- 背景：纯灰/深色渐变纯色背景，无道具、无复杂场景，极简低饱和高级质感
- 定位：高端商业人像、杂志主视觉影视肖像

### 风格2：韩系极简未来轻机械人机融合肖像（科技升级款）
完全沿用原图人物五官、肤色、脸型、辨识度、修身贴身服装轮廓，不使用厚重机甲，轻量化科技改造：
- 面料：纯黑炭黑哑光生物复合功能纤维，衣身嵌入微型传感器、柔性电路纹路，低调简约
- 科技点缀：纤细白色低饱和发光能量线条，仅局部点缀，克制不浮夸
- 面部改造：额头、脸颊、下颌、眼周、颈部轻量化仿生金属嵌片、精密机械衔接组件，人机融合轻度改造
- 画面质感：超写实商业广告大片，干净纯色背景，拒绝重度赛博朋克、夸张机甲、繁杂装饰
- 整体调性：韩式极简未来高级质感，科技品牌主视觉人像

## 前端核心功能说明
### 1. Hero Section 基础布局
- 白色纯净背景Hero区块，人物图片固定放置画面偏右侧
- 页面内置持续动态滚动、随机跳动变化的数字+数据流文字特效（参考 React Bits 动态粒子文字效果）
- 保留原有导航栏、标题文案、操作按钮布局，交互特效不破坏原有页面UI结构

### 2. Canvas 交互式 Reveal 探照遮罩核心特效（重点）
#### 实现逻辑
1. 双层图片分层结构
   - 底层Layer：原始证件照（默认全局展示）
   - 上层Reveal Layer：AI生成风格化人像，全屏覆盖底层图，默认完全透明不可见
2. Canvas 动态生成径向渐变遮罩
   - 隐藏Canvas画布实时绘制**柔边径向渐变圆形蒙版**，中心完全不透明、边缘平滑羽化透明无硬边
   - 将Canvas生成的渐变图作为上层图片 `maskImage / -webkit-mask-image` 遮罩，仅鼠标区域透出第二张AI效果图
3. 鼠标平滑跟随机制
   - 通过 `mousemove` 监听鼠标坐标，搭配 `requestAnimationFrame` 做坐标缓动平滑插值，消除鼠标移动生硬跳动
   - 遮罩圆形区域跟随鼠标实时更新位置
4. 尺寸兼容保障
   两张图片统一尺寸、`background-size: cover`、相同定位规则，遮罩渲染无画面错位、偏移问题
5. 移动端适配
   - 手机端自动关闭鼠标Reveal遮罩交互，页面永久只显示底层原始证件照，无异常报错

#### 技术依赖
纯原生JS + Canvas API实现，无额外重型第三方库，轻量无性能损耗，兼容现代浏览器（Chrome/Edge/Safari）

## 部署&运行方式
### 本地直接打开
直接双击 `index.html` 文件即可在浏览器运行，无需后端、打包工具，纯静态页面。

### 服务器部署（Nginx）
1. 将项目全部文件上传至网站根目录
2. Nginx配置静态资源访问，无需反向代理API（纯静态前端页面）
3. 重载Nginx配置后通过IP/域名直接访问

## 浏览器兼容
- 桌面端：Chrome ≥90、Edge ≥90、Safari ≥15、Firefox ≥88（完整支持遮罩交互特效）
- 移动端：iOS Safari、安卓浏览器（自动禁用遮罩交互，正常展示基础页面）

## 自定义修改指南
1. 替换人像素材
   将新原图覆盖 `assets/portrait.png`，AI生成效果图覆盖 `assets/portrait-reveal.png`，无需修改JS代码，自动适配图片尺寸
2. 修改探照圆形大小/羽化柔和度
   编辑 `revealMask.js` 内配置参数：
   ```js
   const config = {
     radius: 180,        // 柔光圆形半径，数值越大探照范围越大
     feather: 0.75,      // 边缘羽化强度 0~1，数值越高过渡越柔和
     smoothFactor: 0.12  // 鼠标跟随平滑度，数值越小移动越丝滑
   }
3.修改动态数字文字样式
在 style.css 中调整 .dynamic-data-text 字体、颜色、动画速度；修改 dynamicText.js 自定义数字变化频率、文字内容
4.调整 Hero 人物左右位置
修改 css 中 hero-img 容器 background-position 属性，控制人物画面左右偏移
